# Firme Studio

Prototipo responsive de las siete páginas públicas de Firme Studio, primer estudio de pilates de Lima Este (San Juan de Lurigancho). Incluye Inicio, Clases, Horarios, Paquetes, Instructoras, Estudio y Contacto, alineadas con el archivo Figma.

HTML, CSS y JavaScript están incluidos en index.html, junto con las imágenes y el isotipo FS como favicon. Las tipografías se cargan desde Google Fonts.

## Datos reales incluidos
- Disciplinas: Reformer, Barre, Hot, Mat y Dance.
- Frase de marca: "Un espacio creado para nosotras."
- WhatsApp +51 970 886 195 (enlace directo) e Instagram @firme_peru.
- Atención de 8:00 a 18:00 · San Juan de Lurigancho, Lima (solo el distrito).
- Apertura al público el lunes 5 de octubre de 2026; desde ese día se aceptan reservas.
- Pago por paquetes de clases, coordinado por WhatsApp o en efectivo en el estudio (sin comprobante automático por ahora).
- Recordatorios de clase 24 h, 12 h y 2 h antes.
- Dominio: firmestudio.com.pe.
- Textos legales (términos, privacidad, cancelaciones y Libro de Reclamaciones) en borrador, adaptados a la normativa peruana.

## Pendiente de confirmar con el estudio
- Razón social, RUC, dirección legal y correo (necesarios para los textos legales).
- Reglas propuestas: cancelación hasta 8 h antes, tolerancia de 10 min, reserva hasta 7 días antes, 30 min para aceptar un cupo.
- Horario real de clases (el mostrado es de ejemplo).
- Revisión legal de los textos antes de publicarlos.
- Nombres y perfiles de instructoras, precios y vigencias de paquetes.
- Fotos propias: las de Mat y Dance son de reemplazo.

Las reservas, compras y formulario son demostraciones. No hay pagos reales ni envío o almacenamiento de datos personales.

## Handoff para desarrollo
Stack: Laravel + React + Tailwind CSS v4 + shadcn/ui. La carpeta `handoff/` tiene el tema listo para pegar (`firme-theme.css`) y las variantes del botón de shadcn según Figma (`button-variants.ts`). La especificación completa está en el documento de handoff del proyecto.
