# Firme Studio

Prototipo responsive de las siete páginas públicas de Firme Studio, basado en el archivo Figma. Incluye Inicio, Clases, Horarios, Paquetes, Instructoras, Estudio y Contacto.

HTML, CSS y JavaScript están incluidos en index.html, junto con las imágenes originales de Figma. Las tipografías se cargan desde Google Fonts.

Las reservas, compras y formulario son demostraciones. No hay pagos reales ni envío o almacenamiento de datos personales. Los datos de contacto son ficticios y las reglas operativas son supuestos.
